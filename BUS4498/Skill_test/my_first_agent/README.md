# HackTrack

### System Designer Name

Chloe Westberg

### System Name

HackTrack

### Problem Statement

BUS 4498 students receive assignment information in multiple course materials, which makes it difficult to maintain one accurate view of what is due and what has been completed.

### System Goal

For BUS 4498 students, HackTrack will turn provided course announcements, syllabus excerpts, and task lists into an organized assignment tracker so that at least 90% of the provided assignment titles, due dates, and statuses are recorded correctly, improving from a baseline of 0% before each update to a target of 90% after each update, while remaining limited to organizing and flagging course tasks rather than submitting work or changing Canvas records.

### Who Is Better Off When This Works?

BUS 4498 students are better off because they can see accurate assignment deadlines and statuses in one organized tracker.
